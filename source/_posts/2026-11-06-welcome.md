这是站点搭好后的第一篇示例文章。之后写的内容都会出现在首页，也可以从分类、标签和归档里找到。

新文章可以用下面的命令创建：

```bash
npx hexo new post "文章标题"
```

写完保存到 `source/_posts/`，推送到 `main` 分支后，GitHub Actions 会生成页面并发布到 GitHub Pages。
